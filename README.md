# UAST - Portal do Aluno UFRPE / UAST

Sistema de Gestão Acadêmica e Auxílio ao Estudante da UFRPE - UAST (Unidade Acadêmica de Serra Talhada).

## 🚀 Funcionalidades
- **Frequência & Horários**: Calendário com controle de presenças e faltas por disciplina, cálculo de limites regulamentares com alertas.
- **Notas & Médias**: Gestão de avaliações, cálculo de médias finais e históricos por período.
- **Provas & Trabalhos**: Prazos de entrega, lembretes e notificações no navegador (PWA / Mobile / Desktop).
- **Progresso Curricular**: Acompanhamento de integralização do curso (obrigatórias, optativas e complementares).
- **Restaurante Universitário (R.U.)**: Saldo, histórico de recargas e débitos automáticos por geofencing.

## 🛠️ Tecnologias
- React 18 + TypeScript
- Vite + Tailwind CSS + Lucide Icons + Framer Motion
- Firebase (Auth, Firestore, Offline Persistence)
- PWA (Progressive Web App com Service Worker)

## 📦 Como Executar

```bash
cd SITE
npm install
npm run dev
```
